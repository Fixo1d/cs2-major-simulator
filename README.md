# Симулятор мажора CS2: PGL Major Singapore 2026, Stage 1

Модель, которая прогнала первую стадию мажора в Сингапуре **1 000 000 раз**. Для каждой команды она считает шансы на каждый итог (3-0, 3-1 … 0-3) и собирает Pick'Em.

Сделано для канала **«Пиксельный Мажор»**: [YouTube @PixelMajorCS](https://www.youtube.com/@PixelMajorCS) · [Telegram](https://t.me/Fixoidtrade).

> Это шансы, а не пророчество. На прошлых мажорах модель угадала **~60 % матчей**, монетка угадывает 50 %. Stage 1 близок к лотерее, и модель честно это показывает.

## Запустить у себя

Нужен Python 3.9+ и numpy.

```
pip install numpy
python simulate.py              # 100 000 прогонов, ~10 секунд
python simulate.py 2000 500     # 1 000 000 прогонов, как в ролике, ~2 минуты
```

Скрипт печатает таблицу и сохраняет её в `results/my_run.json`. Генераторы случайных чисел зафиксированы, поэтому `python simulate.py 2000 500` совпадает с `results/stage1_result_1M.json` до последнего знака (проверено).

## Как устроена модель

1. **Сила команды и поправка на карту.** Шанс взять карту: `σ(R_A + Δ_A,карта − R_B − Δ_B,карта)`.
   - Модель учится на 3 161 карте за полгода (04.05–02.11.2026). Это все карты команд топ-50 и все карты 32 участников мажора.
   - Свежие карты весят больше: вес падает вдвое каждые 120 дней. LAN — ×1,25.
   - Учитывается не только победа, но и счёт: 13-2 — не то же самое, что 16-14.
   - Якорь — рейтинг Valve (VRS) на 02.11.2026.
2. **Составы.** Старая пятёрка — отдельная «эпоха»: результаты до замен влияют на текущую силу слабее.
3. **Форма игроков.** Средний рейтинг текущей пятёрки за 3 месяца, только в играх против топ-50.
4. **Вето.** Частоты банов и пиков каждой команды с 08.07.2026 (229 матчей). Каждая серия Bo1/Bo3 разыгрывается через вето по регламенту. Пул: Ancient, Anubis, Cache, Dust II, Inferno, Mirage, Nuke.
5. **Швейцарка по регламенту Valve.**
   - 1-й тур: 1–9, 2–10 и так далее.
   - 2–3 туры: высший посев против низшего, без повторов.
   - 4–5 туры: таблица приоритетов, Бухгольц.
   - Матчи на выход и вылет — Bo3.
   - Самопроверка: равные команды дают 12,5 / 18,75 / 18,75 %.
6. **Неуверенность.** Сила команд — не одно число, а распределение (приближение Лапласа, с корреляциями между командами). 2 000 вариантов силы × 500 турниров = 1 000 000.

### Проверка на прошлых мажорах

Остин 2025, Будапешт 2025 и Кёльн 2026: 297 матчей. Модель видела только данные до старта каждого мажора.

| | Угадано серий |
|---|---|
| Монетка | 50 % |
| Модель | **~60 %** (59,9–62,0 % в разных версиях; разброс ±3 % — шум на 297 матчах) |

Подбор настроек под прошлые мажоры точности не добавляет, поэтому настройки не подгонялись.

## Почему нет исходных данных

Карты, рейтинги игроков и вето взяты с **HLTV.org**. Их правила не разрешают распространять выгрузки, поэтому сырых матчей здесь нет. Есть только то, что модель из них посчитала (`data/params_stage1.json`).

Остальные источники:
- **рейтинг Valve (VRS) и составы** — [ValveSoftware/counter-strike_regional_standings](https://github.com/ValveSoftware/counter-strike_regional_standings), `live/2026/details/2026_11_02/`;
- **сетки прошлых мажоров** — Liquipedia.

Чтобы обучить модель заново, положите данные в `raw/` в формате из [`raw/README.md`](raw/README.md) и запустите:
```
pip install numpy scipy
cd pipeline
python stage1_v3.py 2000 500 ../results/stage1_result_1M.json   # симуляция
python run_backtest.py                                           # проверка на прошлых мажорах
python export_params.py ../data/params_stage1.json               # выгрузка параметров для simulate.py
```
